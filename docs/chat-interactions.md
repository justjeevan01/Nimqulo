# Chat dates, replies, read receipts and typing

Direct and group conversations share the same existing typography and bubble layout.

- Date separators use the device's local calendar: Today, Yesterday, or a full date with year. Stored timestamps remain server ISO timestamps; local pending messages receive a timestamp immediately.
- Swipe a committed message to the right to select Reply. Horizontal motion must dominate vertical motion; scrolling, diagonal movement, short drags and cancelled gestures do not select a reply. The composer displays the selected quote and a Cancel reply control. Reply selection and failed messages are cached with the draft.
- Migration 005 stores a reference to the original message. The API validates the conversation, membership visibility and deletion state. Retrying must preserve both text and reply ID. Quotes are resolved from current server records, capped at 240 characters, and replaced with an unavailable notice when deleted or outside the viewer's membership period.
- A single check and Sent indicate a successful server commit. Double checks and Read indicate another recipient's persisted read position; groups display Read by N. Sending and failed messages never claim to be read. Group receipt counts use the recipients present at the message's sequence position, excluding later joiners and the author.
- Merely fetching a conversation does not mark it read. The screen reports viewable committed messages after 300 ms at 65% visibility; acknowledgements run only while that route is focused and Android is active. Read positions advance monotonically and publish realtime invalidations only when they advance. Read updates do not generate push notifications.
- The supplied `design/app-icon.png` is copied unchanged to `assets/images/app-icon.png`. Expo's launcher and Android adaptive icon configuration use that asset. Icon changes require a new native APK.

Typing indicators use authenticated, ephemeral WebSocket events for direct and group conversations. The server derives the sender identity and current permitted recipients; blocked connections and nonmembers cannot publish. Signals contain no draft text and create no messages, push notifications or stored presence. Input pulses are throttled, stop after 2.5 seconds idle or on blur/send/background/navigation, and expire locally within six seconds if a stop is lost. Group bubbles identify the people typing. The staggered three-dot animation uses native opacity/translation, avoids interaction handles, and respects reduced motion.

Typing validation: 25 unit tests, 14 isolated Postgres tests and five coordinator tests passed, including ordered start/stop requests, throttling/idle expiry, spoofed identity rejection, blocked/nonmember authorization, metadata bounds and closing-socket replacement. The deployed authenticated API and WebSocket relay passed live probes. Pixel 8 rendered the temporary visual preview and changing animation frames; the preview was then removed and the bubble correctly disappeared. Two-account physical-device typing acceptance remains part of the existing two-phone release gate.
